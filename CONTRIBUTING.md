# Contributing to SiliconPath

Thank you for helping make semiconductor learning and project planning clearer.

## Useful contributions
- Correct a source listing or explain a resource's access conditions.
- Add a reviewed learning activity with prerequisites, inputs, outputs and assessment criteria.
- Report or fix a reproducible software defect.
- Improve keyboard access, mobile layout, labels or readable copy.
- Document a simulation with reproducible inputs and limitations.

## Before work starts
Open an issue describing the problem, intended output and evidence, or contact arun_gharami@live.com. Agree scope for substantial contributions. Participation does not promise payment, employment, academic credit or certification.

## Workflow
1. Fork the repository and create a focused branch.
2. Read the relevant source and existing documentation.
3. Make a bounded change; explain assumptions and cite original sources.
4. Run `npm run check`, `npm test` and `npm run build` for code or catalog changes.
5. Open a pull request with the problem, change, checks and remaining limitations.
6. Respond to review and agree attribution and handover.

Do not label VM checks as browser verification. Documentation-only changes need link/path and factual review rather than new software tests.

## Source and evidence standards
Prefer original universities, publishers, government and industry sources. Separate source-listing checks from full-text review. Record dates and publication types. Never invent quotes, prices, partnerships, measured results or certification claims.

Do not upload confidential records, credentials, paid publications, proprietary process recipes or assets you lack permission to redistribute. Agree permission before identifying third-party projects or collaborators.

## Collaboration
Be respectful, credit others and focus feedback on evidence and improvements. The maintainer reviews contributions; relevant qualified reviewers are needed for technical or operational claims. Report conduct concerns privately to the project contact.

## Rights
A project-wide license has not been selected. Contributors must identify third-party licenses and agree intended ownership and reuse before substantive work. Public availability alone does not grant unrestricted reuse.
