# Semiconductor Learning — SiliconPath

**Learn the semiconductor journey and produce a documented first learning plan.**

Status: initial educational draft; subject review pending. Prepared 2026-10-14.

An independent SiliconPath learning collection for beginners, students, educators, and prospective technical contributors. No previous cleanroom experience is required.

## Start here

1. Read [the starter pathway](STARTER_PATH.md).
2. Complete [the activity worksheet](ACTIVITY_WORKSHEET.md).
3. Produce a one-page process map and a short next-learning plan.
4. Submit a source-backed correction or improvement through an issue or pull request.

Suggested effort: 3–4 hours. This is a planning suggestion, not a course requirement or certification.

## First deliverable

A semiconductor journey map showing design, wafer fabrication, packaging, board assembly, and testing, with a source and a learning question for each stage. Include one selected skill, an activity, and a way to check your result.

## Contribute

Describe the audience and problem. Use primary sources where possible, attribute third-party material, and distinguish verified facts from examples and proposals. Keep exercises reproducible without specialist equipment. Do not submit private data, proprietary documents, or copied course materials without permission.
